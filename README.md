# Moneyball FM27

Aplicativo desktop para Windows criado a partir do painel web Moneyball FM27.

## Usar no Windows

1. Execute `Moneyball-FM27-1.0.0-x64.exe` (versão portátil) ou o instalador `Moneyball-FM27-1.0.0-x64.exe` da pasta `release`.
2. Importe seus CSV, HTML ou RTF exportados do Football Manager.
3. Use os filtros e exporte a seleção em HTML, RTF ou CSV.

Os dados ficam salvos no perfil local do aplicativo. Para transportar a aplicação, basta copiar o instalador/arquivo portátil; o código-fonte pode ser enviado ao GitHub com esta pasta inteira, incluindo `main.js`, `package.json` e `dist/index.html`.

## Desenvolvimento

```powershell
npm install
npm start
npm run dist
```
